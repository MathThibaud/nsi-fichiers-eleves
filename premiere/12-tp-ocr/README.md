# TP — Reconnaître des chiffres et des lettres manuscrits

Première NSI — Chapitre 12 — Les k plus proches voisins.

Placer tous ces fichiers dans un même dossier de travail.

| Fichier | Rôle |
|---|---|
| `ocr.py` | trame du programme (fonctions à trous, fonctions fournies, tests) |
| `chiffres_train.csv` | chiffres manuscrits d'entraînement (14 x 14 pixels) |
| `chiffres_test.csv` | chiffres manuscrits de test |
| `lettres_train.csv` | lettres manuscrites d'entraînement |
| `lettres_test.csv` | lettres manuscrites de test |

Sources des images : chiffres d'après la base MNIST (Y. LeCun, C. Cortes, C. J. C. Burges), diffusée sous licence Creative Commons BY-SA 3.0 ; lettres d'après la base EMNIST (G. Cohen, S. Afshar, J. Tapson, A. van Schaik, 2017, issue de la NIST Special Database 19). Images réduites en 14 x 14 pixels noir et blanc ; ces fichiers dérivés sont diffusés sous la même licence (CC BY-SA 3.0, https://creativecommons.org/licenses/by-sa/3.0/).
