# TP — Mon premier site, pas à pas

Première NSI — Chapitre 10 — Le Web : réseaux et interactions homme-machine.

Placer tous ces fichiers dans un même dossier de travail.

| Fichier | Rôle |
|---|---|
| `index.html` | page d'accueil du site du Club Astro, à compléter |
| `style.css` | feuille de style, à compléter |
| `script.js` | script JavaScript, à compléter |

Télécharger l'archive, la décompresser, puis ouvrir index.html dans un navigateur et les trois fichiers dans un éditeur de texte. Le TP se fait dans ce dossier.

Tout télécharger d'un coup : [archive premiere-10-tp-site-web-guide.zip](../../zips/premiere-10-tp-site-web-guide.zip).
