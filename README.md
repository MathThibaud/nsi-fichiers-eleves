# Fichiers à télécharger — NSI (Première, Terminale)

Ce dépôt contient les fichiers dont les élèves ont besoin pour les activités,
TP et projets du manuel de NSI : programmes à compléter, données, images.
Il ne contient aucun corrigé.

## Télécharger

- **Un dossier entier** : utiliser le lien « archive .zip » imprimé sous le titre
  de l'activité (ou le QR code), puis décompresser l'archive. Toutes les archives
  sont aussi dans le dossier [`zips/`](zips/).
- **Un seul fichier** : ouvrir le fichier sur GitHub, puis cliquer sur le bouton
  « Download raw file » (flèche vers le bas, en haut à droite du fichier).
